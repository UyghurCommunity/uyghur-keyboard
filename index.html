01 / سىناق مەيدانى

بىر جۈملە بىلەن باشلاڭ.

تېكىستنى تاللاپ، ھەرپ كىرگۈزۈپ سىناڭ.
كورسىرىڭىز تۇرغان ئورۇن ساقلىنىدۇ.

0 ھەرپيېزىشقا تەييار
بۇ ئىختىيارىي ئاھاڭداش ھەرپ خەرىتىسى.سىستېمىڭىزنىڭ ئەسلى كۇنۇپكا ئورۇنلاشتۇرۇشى ئەمەس.

a → ا · q → ق · x → خ · A → ئا · G → غ · N → ڭ · S → ش · V → ئۆ · W → ئۈ · Y → ې

سىستېما كۇنۇپكا تېزلەتمىلىرى ۋە باشقا تىل كىرگۈزگۈچلىرىگە ئارىلىشىشمايدۇ.

02 / تۈرىڭىزگە قوشۇڭ

ئاددىي بىر كۆرۈنمە يۈز.

كۇنۇپكا تاختىسى سىزنىڭ كىرگۈزۈش رامكىڭىز بىلەن ئىشلەيدۇ.
ئېكران ئوقۇغۇچ، كۇنۇپكا تاختىسى ۋە تېگىشنى قوللايدۇ.

Vanilla JavaScript

import { createKeyboard } from '@uyghurcommunity/keyboard';

const keyboard = createKeyboard(
  document.querySelector('textarea'),
  { physical: false }
);

keyboard.insert('سالام');
keyboard.setPhysicalMapping(true);
keyboard.destroy();

Web Component

<textarea id="uyghur-text"></textarea>
<uyghur-keyboard for="uyghur-text">
</uyghur-keyboard>

<script type="module">
  import '@uyghurcommunity/keyboard/element';
</script>

npm بولىقىنى قوللايدىغان تۈر قۇرغۇچىدا ئىشلىتىڭ. بۇ سىناق بېتى يەرلىك مودۇلنى يۈكلەيدۇ.
